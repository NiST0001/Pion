# Pion

给 [pi coding agent](https://www.npmjs.com/package/@earendil-works/pi-coding-agent) 做的桌面客户端，主要是想做个自己觉得好看的外观。

## 主要功能

- 流式回复、思考折叠、Markdown 和代码高亮。可以贴图片、拖文件，或用 `@` 添加参考。
- 管理多个项目和 Git worktree。会话支持后台运行、收藏、复制、分叉和历史跳转。
- 查看 Git diff，按文件或行暂存，提交修改、处理冲突。
- 任务计划、并行子代理，以及在独立 worktree 中运行的多 Agent 工作流。子代理可在父会话下点击查看，结束后临时记录保留半小时，父摘要保留；设置 → 会话可选默认子代理模型，未在会话指定时就使用该设置；也可直接告诉主 AI 哪个子代理使用哪个模型。每批数量可设 1–100，超时可设 1–300 分钟。
- 全局使用总览：累计 SDK 估算费用和 Token、项目/模型分布，以及长期保留的本地使用账本。
- 设置中逐项开关工具、MCP、Skill、扩展和子代理，并提供极简、标准、无 Skill 三种一次性批量操作。
- Codex 生图和参考图编辑，目前是实验功能。
- 内置终端和浏览器、可调整的分栏布局，以及深浅色和“信号橙”等主题。

## 使用

运行需要 Node ≥ 22.19，推荐 Node 24。

打开后，先在设置里配置模型，再选择项目。已有的 pi 用户配置可以继续使用。

提供商的“模型显示”开关可隐藏或恢复模型列表，关闭不会退出登录，也不影响已有会话继续使用。

- **Enter**：发送消息，运行中追加引导。
- **Tab**：排队发送。
- **Shift+Enter**：换行。
- 输入 `/` 查看命令：精确命令按 Enter 执行，部分名称按 Enter 或 Tab 补全；原生命令不排队，也不消耗已附图片。`/plan` 切换计划模式，`/verify` 打开验证，`/agents` 打开多 Agent 工作流，`/stats` 打开使用总览。

Pi 命令正在分阶段接入桌面交互：现有入口包括 `/settings`、`/model`、`/thinking`、`/login`、`/logout`、`/new`、`/resume`、`/name`、`/session`、`/clone`、`/compact`、`/copy`、`/export`、`/trust`、`/hotkeys`、`/changelog`、`/quit`。登录/登出只打开提供商管理，仍需显式点击；`/changelog` 展示内置 Pi SDK 日志，Pion 日志在设置 → 关于 Pion。第一阶段源码接入尚待执行验证。

`/scoped-models`、`/tree`、`/fork`、`/import`、`/reload`、`/share`、`/bug`、`/llama` 仍标注“待接入”，不会送给模型或回退到终端。`/export [path.html|path.jsonl]` 仅导出本地新文件，不覆盖、不上传：HTML 包含会话树，JSONL 只含当前分支；含空格路径加引号，分享前自行检查敏感内容。详细边界见[原生斜杠命令约束](docs/feature-contracts.md#原生斜杠命令)。

生图可以直接说：`画一艘红色小船，保存到 images/boat.png`。编辑图片时，告诉它参考哪张图、保存到哪里就行。

生图需要 Codex 登录和图片额度，参考图会连同元数据上传。codemode 可能调用付费模型；请求失败或取消，仍可能收费或消耗额度。参数、账号要求和 MCP 配置见[开发文档](docs/development.md)。

左上角“浏览器”可打开网页面板，支持地址栏、前进后退和刷新；会话里的网页链接也在此打开，不另开窗口，隐藏后保留当前页面。

分支旁的操作菜单支持重命名和删除分支与工作树。删除前会确认路径；主工作树、未提交或未合并的内容、运行中的会话都不能删除，会话历史保留。

对话里的撤销不会回滚项目文件。工具权限确认不是系统沙箱，内置终端也不受 Agent 的工具确认限制。

项目标题旁可筛选全部/运行中/未运行会话，按手动顺序、更新时间、运行优先或累计 Token 排序，各工作树内生效，不切换或停止会话。Token 是整份已落盘记录累计（含分支），不是上下文占用；未知值排后。自动排序时关闭会话拖排，返回手动顺序恢复。

提问和权限请求默认展开，可手动收起；切换会话保留请求及草稿。左侧栏设置左边的待处理请求按钮悬浮展开会话列表，点击即可跳转，不自动回答或授权；蓝点保留到请求结束。原生选择题支持自定义回答，并可返回选项保留草稿。

### 工具与能力

在**设置 → 工具与能力**中逐项开关。三个快捷按钮只批量修改一次，之后仍可自由调整，不会强制维持某种模式：

- **极简模式**：只开 Pi 自身的 `read/bash/powershell/edit/write/grep/find/ls`，关闭其余能力。
- **标准模式**：全部开关设为开启。
- **无 Skill 模式**：只关闭所有 Skill，其他开关不变。

当前会话空闲时应用；运行中先保存，等本轮实际结束后应用，保留会话和输入草稿。尚无后端时，下次启动使用；读取设置不会启动 Agent 或连接 MCP。

偏好独立保存在 `userData/pion-capabilities.json`，不改写原 Pi/MCP 配置或凭证。开启不等于可用，也不代替项目信任、工具批准、显式工具范围或实验功能门。旧 MCP 插件自行管理的连接需关闭对应扩展入口，隐藏工具不等于断开连接；应用失败会保留已保存设置并提示，不自动重启或重试未知连接。当前为源码接入，尚未执行验证。

### 使用总览

点击左上角工具栏“使用总览”或输入 `/stats`，可查看累计费用、Token、会话/用量记录数、项目/模型分页和近 30 天 UTC 用量。它不随当前项目切换，准备期间也能打开，不会请求模型；打开或手动刷新时完整采集所有可读取会话文件，不设采集容量上限；失败保留上次成功快照。设置 → 会话 → 使用总览可关闭“后台自动采集”（默认开启）。后台低频串行采集、跳过未变化文件，不持续全速扫描。面板支持按年、账期月、日期筛选；年/日按UTC自然年/日，月份可自定每月1–31日开始并记住，短月按月末。费用、Token及各分布同步筛选。

账本保存在 Electron `userData` 下的 `pion-usage-ledger.json`，仅本地保存，采集后删除会话仍保留用量，复制/分叉按已核验来源去重。补录来自固定 SDK 会话根，可能包含共用 SDK 目录中的 pi CLI 等记录，并非全部 Pion 独有。费用是 SDK 的美元估算，不是账单，$0 不代表免费；未采集就已删除、未落盘、生图额度及未报告的外部付费用量不包含在内，覆盖不足会提示，不把未知补零。详见[统计口径与账本约束](docs/feature-contracts.md#使用总览与长期本地账本)；尚未实机验收，不代表已安装或发布。

## 从源码运行

项目使用 Electron、React、TypeScript 和 Vite。

```bash
npm install
./dev.sh
```

构建用 `npm run build`。类型检查、测试、本机安装和打包方法都在[开发文档](docs/development.md)里。
